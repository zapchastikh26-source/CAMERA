# Оцінка камер Caddx

Адаптивна статична сторінка українською мовою. HTML, CSS, локальний шрифт Roboto Condensed (ліцензія в `assets/OFL.txt`), SVG-іконки та PNG камери з прозорим фоном. Встановлення залежностей не потрібне. JavaScript використовується лише для TikTok-аналітики; сторінка та Telegram-посилання працюють без нього.

## Локальний запуск

```sh
cd /workspace/CAMERA
python3 -m http.server 8000 --bind 0.0.0.0
```

## Netlify

Опублікуйте корінь репозиторію. Команду збірки залиште порожньою; каталог публікації — `.` (також задано в `netlify.toml`).

Обидва посилання ведуть на https://t.me/+YhfvqbZIEJI1Y2Ey. Доступність запрошення керується Telegram.

## Перевірка

Перевірено в Chromium на ширинах 360, 390, 768, 1024 та 1440 px: відсутність горизонтального прокручування, завантаження зображення і шрифту, адреси обох посилань, відсутність помилок завантаження ресурсів. Підтримуються клавіатурний фокус і `prefers-reduced-motion`.

## TikTok Pixel

Піксель `DBD1EI3C77UASCMGG0PG` підключено в `index.html`: перегляд сторінки та подія `Contact` при натисканні кожного Telegram-посилання. Параметр `button_location` розрізняє `header` і `hero`. Подія позначає натискання, а не повідомлення чи вступ у Telegram. Перевіряйте доставку на опублікованому сайті через TikTok Events Manager → Test Events. Блокувальники можуть заважати аналітиці; прямі посилання залишаються працездатними.
